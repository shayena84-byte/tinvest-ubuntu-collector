# T-Invest Sandbox v1.7.0 — OpenAI API вместо Ollama

Основной ИИ-движок автономного трейдера снова **OpenAI Responses API**. Локальная Ollama/Qwen3 не требуется. Уже сохранённый ключ читается из ~/.config/tinvest-readonly/openai-api-key, повторный ввод не нужен. Токены не публикуются в GitHub или отчётах.

**Важно:** торговля только в T-Invest Sandbox виртуальными рублями. Реальные брокерские счета не затрагиваются. Существующая аналитика, локальная SQLite и проверки качества рыночного стакана сохраняются.

## Обновить v1.5.0 или v1.6.0 на Ubuntu

~~~bash
cd ~
wget -O tinvest_ubuntu_collector_v1.7.0.zip https://github.com/shayena84-byte/tinvest-ubuntu-collector/releases/download/v1.7.0/tinvest_ubuntu_collector.zip
unzip -o tinvest_ubuntu_collector_v1.7.0.zip
cd tinvest_ubuntu_collector
bash install_openai_backend.sh
sudo loginctl enable-linger "$(whoami)"
~~~

Установщик делает SQLite backup, обновляет веб-панель, сохраняет конфигурации SOCKS5/T-Invest и ключ OpenAI. Отключает все предыдущие таймеры автоматической торговли, включая локальную Ollama. Затем создаёт только один таймер OpenAI с запуском каждые пять минут на минуту позже Market Recorder.

Проверка доступа выполняет GET https://api.openai.com/v1/models/{model}. Если выбранная модель или API недоступны, таймер останется выключенным. Не следует обходить географические условия обслуживания API; размещение и доступ должны соответствовать официальным правилам OpenAI.

## Проверка и управление

~~~bash
python3 ~/tinvest-collector/openai_quality_trader.py doctor
python3 ~/tinvest-collector/openai_quality_trader.py status
systemctl --user list-timers 'tinvest-sandbox-*'
journalctl --user -u tinvest-sandbox-openai.service -n 80 --no-pager
~~~

Пробный анализ (без сделок; в торговые часы):

~~~bash
SSL_CERT_FILE="$HOME/.config/tinvest-readonly/ca-bundle.pem" python3 ~/tinvest-collector/openai_quality_trader.py dry-run
~~~

Остановить виртуальную торговлю:

~~~bash
systemctl --user disable --now tinvest-sandbox-openai.timer
~~~

Возобновить после успешной диагностики:

~~~bash
systemctl --user enable --now tinvest-sandbox-openai.timer
~~~

Вне торговой сессии агент запишет openai_market_closed и не будет обращаться к модели. Проверяйте журнал во время торгов.

## Алгоритм

1. Получает виртуальные позиции и остатки из T-Invest Sandbox.
2. Запрашивает торговые свечи, цены и характеристики допустимых акций.
3. Фильтрует инструменты по записанным в SQLite свежим непересечённым стаканам, стоимости последней цены и спреду.
4. Передаёт очищенный рыночный контекст в OpenAI Responses API, используя имеющийся приватный ключ.
5. Получает решение BUY / SELL / HOLD в структурированном JSON.
6. Независимо проверяет доступные деньги, размер позиции, экспозицию, количество заявок и дневной лимит риска.
7. Перед виртуальной заявкой повторно проверяет состояние Sandbox и свежесть стакана.
8. Отправляет заявки только через SandboxService/PostSandboxOrder. Токен или реальный номер счёта никогда не передаётся модели.

## Лимиты

Максимум 35% виртуального капитала на новую позицию, общая экспозиция не более 80%, резерв минимум 850 виртуальных рублей. Не более 6 заявок в день с 20-минутным перерывом; при дневном снижении капитала на 7% новые покупки запрещены. Только виртуальные рублёвые акции основной доски TQBR, без коротких продаж и плеча. Максимальный спред 0,8%, снимок стакана не старше 10 минут; пересечённые или неподтверждённые книги исключаются.

Конфигурация модели сохраняется в ~/.config/tinvest-readonly/ai-agent.json. Пользовательские пределы риска остаются в силе, но движок не позволяет превышать перечисленные предельные значения.

## Веб-дашборд

Открывается из Windows 11 через SSH-туннель:

~~~powershell
ssh -N -L 8787:127.0.0.1:8787 user@192.168.202.250
~~~

Затем откройте http://127.0.0.1:8787 . Интерфейс продолжает показывать 10 уровней стакана, стоимость исполнения, дисбаланс и фильтр аномалий. Публичный доступ к HTTP-порту не требуется.

## Что нужно понимать

Тесты GitHub Actions не подтверждают фактическую работу API на Ubuntu; это проверяется командой doctor и затем dry-run в часы торгов. Получение HTTP 200 от списка моделей не гарантирует успешный торговый анализ. Стратегия экспериментальна, прибыль не гарантирована; исполнение в Sandbox не воспроизводит полностью реальный рынок, а результат зависит от стоимости операций и динамики ликвидности.

Официальная документация OpenAI: https://platform.openai.com/docs/api-reference/responses
