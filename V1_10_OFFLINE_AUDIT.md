# v1.10.0 — автономный аудит рыночных данных без OpenAI API

Новая команда анализирует локальную SQLite-базу только на чтение. Не использует
OpenAI, T-Invest API, SOCKS5, не открывает и не отменяет торговые заявки.

## Возможности
- Количество реальных пятиминутных записей по каждому инструменту.
- Доля записей `valid`; учёт `stale`, `unverified`, `invalid`.
- Медианный спред среди `valid`, число снимков с широким спредом.
- Отсутствующие интервалы **между первой и последней реально наблюдаемыми
  записями**. Это не календарь торгов и не показатель полноты вне торговых часов.
- Определение облигаций по ISIN даже при ином тикере в таблице instruments.
- JSON и CSV на stdout, без изменения исходной базы.

```bash
unzip -o tinvest_v1.10.0.zip
cd tinvest_ubuntu_collector
```


## Ограничения
Отчёт измеряет качество и доступность собранных данных, но не рассчитывает
доходность торговой стратегии: торговых сделок и истории капитала пока нет.
Без данных о комиссиях, задержках и реальном исполнении нельзя надёжно
оценить прибыльность стратегии. Не интерпретируйте отсутствие записей
во время закрытия биржи как доказательство отказа сборщика.

Код не изменяет работающие службы, системные таймеры, настройки SOCKS5,
брокерские токены, SQLite и существующий код торговли.
