# T-Invest Sandbox v1.6.0 — расширенный дашборд и локальный ИИ

Выпуск объединяет только читающий Market Recorder/Dashboard и экспериментального ИИ-трейдера для виртуального T-Invest Sandbox.

## Развёртывание поверх v1.5.0

~~~bash
cd ~
wget -O tinvest_ubuntu_collector_v1.6.0.zip https://github.com/shayena84-byte/tinvest-ubuntu-collector/releases/download/v1.6.0/tinvest_ubuntu_collector.zip
unzip -o tinvest_ubuntu_collector_v1.6.0.zip
cd tinvest_ubuntu_collector
bash install_v1_6.sh
sudo loginctl enable-linger "$(whoami)"
~~~

Установщик сохранит резервную копию SQLite, обновит браузерный интерфейс, добавит до 10 отслеживаемых инструментов, восстановит пятиминутный сбор и установит отдельный user systemd timer для локальной ИИ-модели. Старые таймеры OpenAI/EMA останутся выключенными.

## Локальная Ollama

Из-за недоступности OpenAI API в текущем регионе используется локальная Qwen3:4b через Ollama. Это отдельная модель, не текущий чат ChatGPT. Она не обращается в OpenAI API. Требуется загрузить примерно 2,5 ГБ модели и иметь дополнительную свободную RAM.

Официальный установщик: https://ollama.com/download/linux

~~~bash
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
ollama pull qwen3:4b
python3 ~/tinvest-collector/ollama_sandbox_agent.py doctor
~~~

Модель должна отвечать на http://127.0.0.1:11434 только локально. Если её не было в момент установки v1.6.0, AI-таймер останется выключенным, после успешного doctor включите:

~~~bash
systemctl --user enable --now tinvest-sandbox-local-ai.timer
~~~

Журналы и проверка:

~~~bash
systemctl --user list-timers 'tinvest-sandbox-*'
journalctl --user -u tinvest-sandbox-local-ai.service -n 80 --no-pager
python3 ~/tinvest-collector/ollama_sandbox_agent.py status
python3 ~/tinvest-collector/ollama_sandbox_agent.py dry-run
~~~

Вне торгового времени dry-run выведет local_market_closed. Для одной виртуальной сделки по решению модели в торговую сессию можно вызвать сервис:

~~~bash
systemctl --user start tinvest-sandbox-local-ai.service
~~~

**Полная остановка торговли:**

~~~bash
systemctl --user disable --now tinvest-sandbox-local-ai.timer
~~~

## Ограничения операций

- Только T-Invest SANDBOX и виртуальный счёт; никакой реальной торговли, никаких вызовов Production PostOrder.
- Модель выбирает BUY, SELL либо HOLD, актив и число лотов; модель не может напрямую вызвать брокерский API.
- Дальнейшие проверки кода: валидная торговая доска TQBR и UID, доступные средства, отсутствие непроверенных заявок, не более 35% капитала на новую позицию, не более 80% вложений всего, наличный резерв 850 руб., не более шести виртуальных заявок в день, интервал 20 мин, дневная пауза покупок при просадке 7%.
- Принудительная проверка качества рыночных данных из SQLite перед сделкой: свежий стакан, Bid меньше Ask, спред не более 0,8%, расхождение котировки и середины книги не более 2%.
- Запрет непокрытых продаж и маржинальных поручений; один непризнанный ордер блокирует остальные.
- В Sandbox рыночные поручения исполняются по последней биржевой сделке, а не обязательно по стакану; результат не воспроизводит настоящую биржу.
- Никаких гарантий прибыли. Продукт экспериментальный, результаты желательно сравнивать с пассивным виртуальным портфелем.

## Расширенная аналитика

Веб-панель доступна по адресу http://127.0.0.1:8787 через существующий SSH-туннель Windows:

~~~powershell
ssh -N -L 8787:127.0.0.1:8787 user@192.168.202.250
~~~

Реализованы 10 уровней Bid/Ask, динамика дисбаланса, моделирование средневзвешенной цены по доступным объёмам для 1, 10, 20, 50 и 100 лотов, фильтрация аномалий по статусу и инструменту. Оценка исполнения учитывает только видимые уровни; для облигаций это процент от остаточного номинала без НКД, для акций — рубли за акцию. **Это не денежный итог заявки и не гарантия исполнения.** При отсутствии актуальных корректных данных расчёт отключён.

Отдельный read-only маршрут JSON для интерфейса: GET /api/book?symbol=SBER&board=TQBR&hours=24. Никакие пользовательские счета или API-токены из браузера не выдаются.

## Мониторинг активов

В конфигурацию market-recorder.json добавляются не более десяти инструментов: SBER, MOEX, YDEX, ROSN, LKOH, NVTK (акции TQBR); Омега БО-01 RU000A1092T7, МГКЛ 001Р-04 RU000A106MV2, ОФЗ 26232 SU26232RMFS7, ОФЗ 26251 SU26251RMFS7 (облигации TQCB). Точные коды/торговые режимы должны подтвердиться в T-Invest Sandbox. МГКЛ и Омега доступны только для мониторинга — локальный трейдер облигации не покупает.

## Мониторинг результатов

~~~bash
python3 ~/tinvest-collector/market_recorder.py report --hours 24
python3 ~/tinvest-collector/market_recorder.py export --hours 168
tail -n 20 ~/.local/state/tinvest-sandbox-trader/ai-decisions.jsonl
tail -n 20 ~/.local/state/tinvest-sandbox-trader/virtual-equity.jsonl
~~~

Изменение виртуального капитала без учёта новых пополнений Sandbox не отражает чистую доходность; не вносите дополнительные виртуальные средства, если хотите сравнивать результат. Система не обучается на сделках автоматически и не гарантирует рост капитала.

При ошибках смотрите журналы systemd, а не отключайте контроль качества. Текущая версия ориентирована на безопасное тестирование на виртуальных средствах, а не на реальные инвестиции.
